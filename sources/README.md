The upstream main revision recorded at compilation is [`adc7f1241b42e322a6451854ab7e4b4c146bf78a`](https://github.com/openai/math/tree/adc7f1241b42e322a6451854ab7e4b4c146bf78a). Each review links both to this pinned revision and to the current path on main. A hash identifies bytes; it does not certify a theorem.

The matrix-multiplication entry uses the October 2 path. The exact versions used in earlier conversation turns are unknown. No claim is made that the current repository snapshot is identical to every historical reading.

The nine queued entries have title-based notes and source links only; they were not promoted to manuscript-based reviews during repository creation. Paper PDFs are intentionally not included; follow the source links and the upstream repository's terms for their use.
